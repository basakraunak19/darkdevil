# DEVIL MD

WhatsApp multi-session bot with a mobile-friendly DEVIL MD pairing portal.

## Setup
1. Use Node.js 20 or newer.
2. Fill in the required values in `config.js` and `.env` as needed.
3. Install dependencies with `npm install`.
4. Start the app with `npm start`.
5. Open the port printed in the console to access the DEVIL MD website.

The website uses the existing `/pair/:num`, `/sessions`, and `/plugins` endpoints. Pair only WhatsApp accounts you own or have permission to manage. Keep session credentials and deployment environment variables private.
